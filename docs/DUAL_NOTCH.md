# Archsport + matci 노치 공존

2026-10-18. 두 확장의 최신 버전은 동일한 `notchDock.js`/`dockModel.js`를 동봉한다. 별도 서비스 없이 GNOME Shell의 버전 고정 registry를 사용하고, 각 확장의 enable/disable 수명 안에서만 등록한다.

- 둘 다 켜면 패널 아래에 두 개의 섬이 하나의 중앙 그룹으로 배치된다.
- 사용자가 한쪽을 펼치면 다른 쪽은 접힌다. 수동 검토(100), 경기 이벤트(80), 메모리 제안(30)의 우선순위를 적용한다.
- 수동 검토 중 자동 경기 이벤트는 점수 갱신을 compact 상태로 유지한다. 이벤트가 사용자 검토를 강제로 닫지 않는다.
- 노치 간격은 8 logical px, 모니터 좌우 여백은12다. 폭이 부족하면 활성 노치를 유지하고 상대는 기존 패널 메뉴로 접근한다.
- 한 확장을 끄면 남은 노치는 다시 중앙으로 이동한다. 각 확장의 worker와 사용자 설정은 독립적이다.
- 모션은 기존320ms EASE_OUT_CUBIC, 전역 모션 감소를 따른다. 패널 시계·클릭 영역을 덮지 않는다.

두 확장을 모두 최신 공존 버전으로 업데이트해야 한다. 구버전 Archsport는 이 배치에 등록하지 않는다. 설치는 각 저장소의 `tools/install_extension.py --upgrade`를 사용한다. matci 저장소는 독립 프로젝트다.

검증 범위: Node의 순수 geometry/우선순위 테스트와 기존 Python 축구 테스트. 실제 Ubuntu GNOME에서 두 확장 활성·배율·절전·포커스·패널 클릭은 아직 미검증이다. metadata의 버전 선언이나 Node 구문 검사를 실기 통과로 보지 않는다.
