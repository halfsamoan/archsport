# 현재 GNOME 화면과 실제 레퍼런스의 차이 · 2026-10-19

근거: [사용자 제공 4장](reference-board/README.md), [13개 원본 링크](reference-research.md),
현재 v15/v12 source/installed SHA 일치. 순위는 현재 두 캡처에서 사용자가
처음 보는 면적과 정보 순서에 따른 **디자인 판단**이다. 수치 실험 결과가 아니다.

| 순위 | 차이 | 현재 관찰 | 목표 / 검수 |
| --- | --- | --- | --- |
| 1 | 너무 밝은 표면 | 두 현재 캡처가 밝은 회색 카드 | 기본·밝은 테마 모두 검은 표면. 예외 문구는 대비 유지 |
| 2 | 위쪽 둥근 모서리 | 상단도 24px 둥글어 떨어진 카드로 보임 | 상단 0–4px, 하단 22–26px 후보로 실제 스크린샷 비교 |
| 3 | 과한 높이와 빈 영역 | matci 정상 화면이 두 앱 행 외에 넓은 빈 곳을 차지 | 자연 높이로 수축. review/error는 필요한 만큼 확장 |
| 4 | 스크롤이 주요 요소 | 회색 세로 막대가 경기/앱 옆에 항상 보임 | 기본 항목 수를 줄여 무스크롤, 넘칠 때만 얇은 thumb |
| 5 | 버튼의 무게 | 설정/접기가 기본부터 회색 원 | 28px 투명 hit area, hover/pressed에서만 wash, focus는 유지 |
| 6 | Archsport 정보 누적 | 다음 3 + 최근 6 + 세부 문구가 한 표면에 누적 | 다음 3, 최근 2. 라이브는 스코어·분·최신 이벤트 우선 |
| 7 | matci의 기본 설명 | 시스템 RAM, PSI 0.00, 앱별 입력 —가 앞에 보임 | percent, used/available, meter, 상위 앱 3–5, Review. 경고/검토 설명은 보존 |
| 8 | 타이포 계층 | 날짜/팀 공식명/라벨이 비슷한 크기와 굵기로 경쟁 | 13–14 제목, 12 주정보, 11 보조, 28 hero 시작값 |
| 9 | 내용과 모션 연결 | root 크기 전환 중 children 재구축, actor scale 사용 | 상단 중심 morph와 지연된 보조 내용. native reversal 검증 필요 |
| 10 | 재료 깊이 | CSS solid 색만 있음 | 어두운 tint 우선. Shell BlurEffect BACKGROUND는 타입 존재 확인, 렌더/비용은 미검증 |

**폭 판단:** 붙여넣은 문구의 400–440px 확대 지시는 현재 source의
344/388/368px보다 넓다. 현재 캡처의 물리 픽셀을 논리 px과 혼동하지 않고,
기본 폭은 유지한 채 내용·높이·형태를 먼저 고친다.

**기능 경계:** matci의 보호 이유·PSS/RSS 근거·미저장 작업 위험은 삭제하지
않고 선택/검토 상태나 접근성 이름에서 명확히 유지한다. Archsport는 실제
구단 crest를 유지한다. worker/API/safe-close/shared dock 계약은 건드리지 않는다.
